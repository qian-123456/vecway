# Vecway 移动端产品需求文档 (PRD)

---

## 1. 目标与定位

为 `Vecway` 构建一个高性能、免安装的移动端 Web 控制台（React 19 + TypeScript + Vite + Tailwind v4），直连电脑宿主后台，在手机上流畅运行完整的 AI 编码代理工作流。

**核心解决问题**：
1. 解决手机端中文输入法打字卡顿、频繁回流掉帧问题。
2. 解决长对话与流式输出时的整段重渲染问题。
3. 补齐代理工作流：子代理监控、规划模式闭环、交互问答澄清、工具审批与图表渲染。

---

## 2. 视觉规范

移动端界面与交互的权威视觉合同见 [`docs/MOBILE_DESIGN.md`](./MOBILE_DESIGN.md)。本 PRD 定义产品能力与行为，不重复或覆盖视觉规范。该设计合同包含屏幕布局、组件、深浅色 token 与 390×844 验收条件。

---

## 3. 产品行为原则

- **Agentic coding & AI-first**：Vecway 是指挥、审查、批注与引导 AI 编码代理的工作台，而非传统手写代码 IDE。不搬运传统手工编码 IDE 中对 AI 编程无必要的冗余功能，优先保障代理审查、批注、引导与验证流程。
- 用户可使用浅色或深色主题，并可跟随系统或在设置中手动选择。
- 关键信息（模型、目录、代码、报错）应完整可读；无法避免的截断必须提供查看完整内容的操作。

---

## 4. 功能规划与需求清单

### 4.1 首页与空白新对话 (Home & Empty Chat)
- **统一启动画布**：首页与新建空白对话共享同一套启动画布——居中展示“今天想做点什么？”，不显示任何用户名或头像昵称；展示当前激活项目目录及切换入口；底部输入区使用统一的提示占位文案。
- **结构精简**：移除“聊天／任务”切换标签。
- **快速发起**：底部胶囊输入框直接键入内容发送，后台按所选目录绑定并创建会话，平滑进入对话流，无“会话不存在”中断。

### 4.2 左侧导航全屏抽屉 (Left Drawer)
- **顶部固定项**：发起新对话、搜索会话、定时任务。
- **视图切换**：
  - 空间切换器（代码、通用对话、学习等空间）。
  - 「按项目 / 按时间」双视图切换。
  - **按项目**：保留「项目 → 已注册工作树 → 会话」拓扑。移动端按 `workspaceId` 关联并复用已注册工作树（包括项目目录外的路径），使用所选工作树实际 `cwd` 创建会话，不以路径前缀推断归属。移动端没有创建 Git 工作树的 API；需要新工作树时，提示用户在桌面端创建并注册后再返回移动端，不得静默回退到项目主目录。
  - **按时间**：按时间轴倒序排列会话，带运行状态点。
- **底部常驻项**：
  - 收件箱（铃铛图标，带未读角标，聚合待处理事项）。
  - 订阅与配额（直达配额看板）。
  - 设置（直达系统设置）。
- **剔除内容**：移除与产品无关的库、学生、自定义、视频、笔记本等条目。

### 4.3 对话与输入区 (Chat & Composer)
- **顶栏**：菜单按钮紧邻**左对齐标题区**（展示当前会话「模型名 · 思考强度」或首页/工作区标题），右侧最多保留 **2 个图标按钮**（「新建对话」+「右侧工作区抽屉」开关，取代旧版 `…` 底部菜单及独立工具跳转）；外观以设计合同为准。
- **锚定下拉浮层**：顶部栏触发器（模型选择、目录/上下文、更多操作等）及行内触发器优先从触发位置就近展开锚定浮层（`AnchoredPopover`），取代所有入口一律弹底部抽屉的做法。
- **模型与供应商选择器**：采用适配移动端的桌面端双栏布局——左侧为「最近使用」与已配置供应商列表，右侧为清晰可读的模型名称列表及上下文窗口溢出警告提示，支持能力驱动的思考强度选择。
- **状态栏（输入框上方）**：
  - 左侧：当前工作目录（点击从触发点就近展开完整路径与切换面板）。
  - 右侧：上下文用量百分比（点击呼出压缩面板，支持一键压缩上下文）。
- **加号菜单（原生附件与工作流动作）**：
  - 文件/图片（上传附件；图片以原生图片块发送，输入区与消息内以无文件名、带序号的方形缩略图呈现，点击打开支持多图左右滑动切换的预览画廊）、Finder 选中项（远程文件选择）、在项目中工作（切换项目目录）、目标（设置会话目标）、规划模式（切换 Plan 模式）、草图（手绘白板）。
- **右侧双操作按钮**：
  - **语音输入（麦克风）**：按住/点击录音，调用语音识别模型接口转写文字，填入输入框供编辑，不自动发送。
  - **发送 / 停止**：空闲为发送，生成中自动变为停止按钮；有草稿或附件时可并排暴露发送。

### 4.4 代理工作流深度支持
- **子代理胶囊 (Subagents)**：
  - 挂载于消息区右上角，有子代理活动或记录时常驻显示进度与状态计数（运行/排队/完成/失败）。
  - 点击弹出嵌套树状概览抽屉（展示层级连线、模型、耗时）。
  - 点击单个代理进入全屏详情页（任务要求、思考折叠、工具调用参数与结果、产出、报错）。
- **规划模式闭环 (Plan Mode)**：
  - 通过加号菜单或 `/plan` 开启，输入区显示规划模式横幅；仅当当前会话在 Plan Mode 下产生方案时，从底部拉起可全屏的计划弹窗查看方案，并支持向下拖拽收起为底部悬浮条、点击悬浮条随时重新打开（计划不放入右侧工作区抽屉）。
  - 计划卡片支持复制与下载 `.md` 文件。
  - 计划底部提供明确双按钮：
    - **「执行计划」**：发送确认指令并自动退出规划模式，开始实施。
    - **「修改计划」**：保持规划模式，焦点回到输入框继续补充要求。
- **划词批注 (Text Annotation)**：
  - 统一桌面端与移动端划词体验：长按选中对话文本时屏蔽系统原生 iOS 弹出菜单（callout），弹出自定义上下文菜单，提供 **「批注」**（引用回填至主对话输入框）、**「批注到辅助对话」**（打开右侧工作区抽屉的辅助对话并携带引用）、**「复制」** 与 **「全选」**；不设收集箱逻辑。
- **交互澄清问答 (Questions & Choices)**：
  - Agent 发起澄清时，支持单选框、多选框及自定义文字补充。
  - 多题支持翻页计数（问题 X/Y）、跳过与失败重试。
- **工具审批 (Approvals)**：
  - 就地展示命令正文与参数，支持「单次允许」、「本会话记住」以及多工具批量审批。

### 4.5 富媒体与可视化 (Visualize & Mermaid)
- **Mermaid 流程图**：流式生成未闭合时维持纯文本代码，闭合后懒加载渲染为隔离 SVG，支持全屏双指缩放（最高 6 倍）与平移。
- **Visualize 沙箱小部件**：带安全 CSP 的独立 iframe 渲染交互式 HTML 片段，通过 postMessage 桥接主题变量与状态保存，支持全屏预览与移动端排版重叠自适应。

### 4.6 右侧工作区抽屉 (Right Workspace Drawer)
取代旧版 `…` 底部菜单及独立页面跳转，以**右侧工作区抽屉**镜像桌面端右侧边栏（顶栏右侧按钮 1 次点击或右边缘左滑 1 步呼出，按会话保持各标签页挂载与存活状态），覆盖 5 项 AI 编程工作流面板：
1. **辅助对话 (Sidechat)**：轻量独立旁聊，支持主对话与终端划词一键「批注到辅助对话」，并支持一键将讨论结论整理回传主对话。
2. **Git 审查 (Git)**：面向 AI 改动的审查与提交——差异预览、单文件与批量暂存、Commit 历史查看、AI 建议生成提交信息与本地提交（分支切换等高级操作默认折叠收纳，不设破坏性放弃修改按钮）。
3. **文件 (Files)**：面向 AI 编码审查——优先展示当前会话 AI 引用或修改过的相关文件，并提供工作区目录树只读浏览与语法高亮预览（不设传统手工代码编辑器）。
4. **终端 (Terminal)**：适配深浅色主题的交互式 xterm 命令行，支持以**不可分割的命令/输出整块**进行多选并一键「批注」或「批注到辅助对话」；带移动端专用辅助按键栏（Tab、Esc、Ctrl、方向键），支持优雅关闭终端。
5. **服务 (Services)**：监控本地 Dev Server 后台端口与 PID，支持服务预览及确认后安全停止。

### 4.7 全局设置与配额看板 (/settings & /quota)
- **设置分类**：严格沿用电脑端 6 大分类原始名称，外观以设计合同为准：
  - 常规（通用、外观、通知、隐私；移除存储空间与快捷键；隐藏电脑独占项）。
  - 模型（模型与供应商、模型角色[保留批量替换]、思考与采样、辅助模型、备用模型与重试、上下文窗口、订阅与配额）。
  - 会话（会话、收件箱、会话体检[只读]、规则文件[查看并编辑]、系统提示词[只读]）。
  - Agent 能力（工具、子代理[可新建+AI帮写+编辑已有]、记忆[编辑笔记，保护技能不被误删]、技能与命令）。
  - 连接（连接与设备[原手机访问改名]、MCP 服务器[查看+添加+编辑]、联网搜索）。
  - 帮助（使用教程、版本与更新[只读]）。
- **订阅与配额看板 (/quota)**：
  - 统一汇总展示所有已配置平台（ChatGPT Plus/Pro、Claude Pro 等）的官方限额看板。
  - 呈现 5 小时与 7 天滚动限额进度条、重置倒计时与绑定账号明细。

## 5. 性能与架构契约

1. **输入框非受控隔离**：文本域不绑定 React 同步受控状态，输入法（IME）合成期间零状态发射、零强制布局重测，4 倍 CPU 降频下按键响应 $\le 0.5\text{ ms}$。
2. **流式 60fps 帧率合批**：高频数据推送收敛至 `requestAnimationFrame` 统一调度刷新。
3. **长对话 40 轮窗口**：DOM 树仅保留尾部 40 轮交互，历史消息按需向上分页，挂载节点数控制在 50 个以内。
4. **重模块按需打包**：Mermaid（~2MB）、xterm 终端独立动态分包，主首屏资源体积 $< 250\text{ KB}$。
5. **后台推送精确防扰**：设备处于前台活跃浏览当前会话时不弹推送；离开会话或切至后台时正常接收 Web Push。

## 6. 验收基准与交付检查

- **自动化检查**：交付时运行并报告全量类型检查、测试和移动端生产构建的实际结果；测试数量随代码变化，不在本 PRD 固定测试文件或用例数，也不预先宣称通过。
- **视觉验收**：以 [`docs/MOBILE_DESIGN.md`](./MOBILE_DESIGN.md) 为准，在 390×844 视口检查首页与空白新对话画布、左右抽屉、锚定下拉浮层与双栏模型选择器、对话与划词批注、图片画廊、加号菜单、规划模式、问答表单和配额看板的深浅色表现，确认无水平溢出、无“会话不存在”中断。截图必须对应最终代码；旧截图需注明日期与限制，不能代替最终验收。
- **版本归档**：全部验收通过后，显式暂存任务相关文件并生成英文 Conventional Commit 本地提交；未经授权不推送。验收或所需批准尚未完成时，不暂存、不提交。
